# Basic (Claude 101) — one-page cheat sheet

Print this. Read it the night before the quiz.

### Claude in one line
Thinking partner — not a search box. Trained with **Constitutional AI**. Steerable, transparent, safe by design. Available on **Free, Pro, Max, Ultra, Team, Enterprise**.

### Where Claude lives
- **Claude.ai** — web, desktop, mobile (chats, projects, memory sync across devices).
- **Claude Code** — agentic coding tool for developers.
- **Claude Tag** — Claude inside Slack.
- **Claude Design** — build interactive prototypes from a description.
- **Claude for Microsoft 365** — sidebar in Excel, PowerPoint, Word, Outlook.

### Context window
200K tokens default; up to **1 million** on paid plans with supported models.

### Models
- **Opus** — hardest work.  
- **Sonnet** — the default day-to-day.  
- **Haiku** — fastest, cheapest.  
Switch mid-chat is allowed.

### Three shapes of work
| Shape | For | Lives in |
|---|---|---|
| Turn by turn | Thinking together | Chat |
| Hand off | Multi-step, saved files, scheduled | Cowork (paid) |
| Build software | Coding | Code tab / Claude Code |

### Prompt frame
1. **Set the stage** — who you are, what for.  
2. **Define the task** — write / analyse / build.  
3. **Specify rules** — tone, format, examples.

### Projects = **knowledge**
Instructions + knowledge base + grouped chats + memory.  
Big knowledge base ⇒ **RAG** (up to 10× effective capacity).  
Team/Enterprise sharing: **Can view**, **Can edit**, **Owner**.

### Skills = **process**
Folder of instructions Claude loads for a task.  
Need **Create and edit files** ON.  
Easiest to make: **talk to Claude**.  
Install only from trusted sources.

### Artifacts
Stand-alone outputs (doc / deck / design / chart / code) in their own window; saved in the **Artifacts tab**.  
Three ways to change: **edit directly**, **comment**, **ask in chat**.  
Export: .pptx, .docx, PDF, Google Docs/Slides.

### Connectors
Open standard: **MCP**.  
Web connectors (cloud) + Desktop extensions (local).  
Claude sees only what **you** see.  
Permissions are scoped and revocable.  
Atlassian = Jira + Confluence.

### Research mode
Paid plans. 5 to 45 minutes. Many sources. Cited report.

### Common traps
- Projects don't share memory across each other.
- Connectors don't go hunting on their own.
- Files uploaded in a chat (not to the Project knowledge base) stay in that chat only.
- Docs embed snapshots, not live data — ask Claude to refresh.
